# URLバトラー v0.4 バトル設計

## 目的

結果が「乱数で何となく決まった」ように見えないことを最優先する。

プレイヤーがカードを見た時に予想した長所が、実際の戦闘演出と結果へ反映されるようにする。

## 5能力

- 耐久: 最大HPの基礎。総転送量・DOM・リクエスト数が主因
- 火力: 通常攻撃。画像量・コンテンツ量・DOM等が主因
- 守備: 被ダメージを抑える。HTTPS・Best Practices等が主因
- 速さ: 行動順と会心率へ影響。Performance / FCP / LCP / TBT等が主因
- 技術: コード系攻撃。JS・CSS・外部ホスト・複雑度等が主因

## 数値レンジ

v0.3の「正規化1.0 = 999」を廃止。

通常の正規化最大は約920に抑え、生データがさらに極端な時だけLegendary Boostを追加する。

例:

- 非常に高速: 900前後
- Performance 100 + LCP 350ms未満 + FCP 250ms未満 + TBTほぼ0: 950超候補
- 999: その中でも極端な実測値が必要

「上限到達」が日常化しないようにする。

## 戦闘の基本

完全自動戦闘。

最大18ターン。

1ターンに両者が1回ずつ行動する。

行動順は速さを中心に決まり、ランダム幅は±4%程度に限定。

同程度の速さなら揺らぐが、100以上差があれば基本的に速い側が先行しやすい。

## 攻撃の種類

### 火力攻撃

火力 vs 相手の守備。

カードタイプごとに名前を変える。

- 軽量型: 高速リクエスト
- 画像型: ビジュアルラッシュ
- 重量型: メガバイトプレス
- 複雑型: DOMコンボ
- 古代型: 古代の一撃
- その他: ウェブストライク

### 技術攻撃

技術値が高いカードほど選びやすい。

攻撃名は「コードバースト」。

守備だけでなく相手の速さも一部防御計算に使う。

## 乱数

通常ダメージのランダム幅は約±6%。

会心率は約2.5〜16%で、速さ差によって変動。

カードの能力差をひっくり返すほどの大乱数は入れない。

番狂わせは固有技・会心・相性の重なりで起こす。

## 固有技の意味

- 神速: 初ターン先制 + 最初の一撃強化
- 古代HTML: 速さ+12%
- 重装要塞: 最大HP+18%、速さ-8%
- 巨大生命: 最大HP+25%
- 魔術過積載: 技術攻撃強化、速さ-8%
- 無の境地: 技術攻撃耐性
- 三重結界: 全被ダメージ-10%
- 第三者召喚: 開幕ランダム能力+10%
- DOM迷宮: 守備+10%
- 鉄壁: 守備+12%
- CSS甲冑: 守備+7%
- 静寂のページ: 一定確率で回避
- 画像弾幕: 火力攻撃後に一定確率で追加攻撃
- 揺らぐ大地: 一定確率で高威力化

## 納得感のための表示

戦闘中:

- ターン数
- 攻撃名
- ダメージ
- 会心表示
- 固有技カットイン
- HPゲージ
- 「火力XXX vs 守備YYY」の簡易根拠

戦闘後:

3つの「勝因」を自動生成する。

候補:

- 速さで先行
- 火力差
- 守備差
- 耐久差
- 技術差
- 固有技の発動
- 与ダメ / 被ダメ効率
- 最後の決め手

詳細ログを開けば全ターンを確認可能。

## SNS結果

結果カードには最低限以下を表示。

- 勝者名
- ターン数
- 戦闘力
- 5能力
- 第一勝因
- 対戦カード名
- #URLバトラー
- URLバトラーURL
