# URLバトラー 作業引き継ぎ 2026-08-27 08:56 JST

## 対応概要

今回の更新では、公開中のURLバトラーと受領したソースを確認したうえで、戦闘UI、カード画像、能力バランス、特殊スキル、召喚後導線、お気に入り相棒固定、バックアップ、フッター導線を更新した。

## 実装内容

### 1. バトルを全画面モーダル化
- 通常対戦、おまかせ対戦、連戦、URL魔塔の戦闘表示を `battleDialog` に統一。
- 戦闘画面はビューポートと同サイズの上レイヤーとして表示。
- プレイヤーを左下、相手を右上に配置する対角レイアウトへ変更。
- スマホでは戦闘ステージ高を抑え、1画面内で双方の相棒とHPを確認しやすい構成に変更。
- 演出速度 `×1 / ×2 / ×4` と「結果までスキップ」はモーダル上部へ移動。
- バトルログはステージ直下へ常時表示。スキップ時も最終ログをまとめて表示する。

### 2. カード共有画像
- 相棒モンスター欄の名前・補足情報の中心位置を調整。
- 相棒欄の左側に5能力レーダーチャートをCanvas描画で追加。
- 共有画像下部の `#URLバトラー` とゲームURLを削除。
- 特殊スキル表示数を最大2個に合わせた。

### 3. 特殊スキル
- 自動生成カードの特殊スキル数を最大2個へ変更。
- 固定NPCも最大2個に統一。
- Web史・記録で知られるURL向けの強クラススキルを追加。
  - `Web殿堂`：主要能力強化
  - `始原のWeb`：守備・技術強化
  - `百万陣`：火力強化＋追撃
- Webクリエイターボックスの記事に掲載されている代表的なホストを判定対象へ追加。

### 4. 能力バランス
- `BALANCE_VERSION` を 8 へ更新。
- Lighthouseのスマホ計測が一律に遅く見えやすい点を補正し、PC/スマホの速度差を圧縮。
- 軽量ページの速度ボーナスを弱め、通常条件では速度を最大988に制限。
- 速度999は、超軽量・Performance 100・LCP 450ms未満・TBT 0・極少リクエスト等が同時成立した場合だけ出る条件へ変更。

### 5. 召喚後の導線
- 召喚成功時にURL入力欄をクリア。
- 成功メッセージでページ上部へ戻さず、生成されたカード結果へスムーズスクロール。
- 失敗時は従来通り上部のエラー表示へ移動。

### 6. 相棒モンスター固定
- マイカードに `相棒を固定 / 相棒固定解除` を追加。
- 固定情報は `localStorage` の `urlbattler.buddy-locks.v1` に端末ローカル保存。
- 最新データへの更新や能力再計算後も、固定中は同じ相棒を優先。
- カード削除時は対応する固定情報も削除。

### 7. お気に入りバックアップ
- 新規 `07 設定` タブを追加。
- お気に入りカードと相棒固定情報をJSONで出力可能。
- JSONバックアップの読込・復元を追加。
- 読込時は現行バランスバージョンで再計算する。

### 8. フッターリンク
- PORTAL / GAMES / TOOLS / ABOUT / PRIVACY / TERMS / DISCLAIMER / CONTACT を追加。

### 9. .agents
- 受領した `.agents.zip` の内容をリポジトリ直下 `.agents/` に展開。
- 日本語ファイル名 `Pink Elephant Guard ピンクの象ガード仕様書.md` はUTF-8名のまま保持。
- `rpg-scenario-polisher` は別ゲーム向けの内容なので、URLバトラーの実装判断には適用せずファイルのみ取り込んだ。
